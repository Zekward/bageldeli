A running journal of the improvement loop: each cycle plans changes, implements them,
records what changed, and derives the next cycle's work from those insights.

## Cycle 1 — Correctness bug sweep

### Plan
Fix concrete, user-visible bugs found while reading the codebase before adding features.

### Findings → Fixes
1. **`floating-card.tsx`**: a stray backtick (`` ` ``) after the `<Image />` tag renders a
   literal "`" character floating on the popup. → Remove it.
2. **`discounts/page.tsx`**: `className="... bg background ..."` is a typo — `bg background`
   are two broken tokens instead of `bg-background`. The card has no background. → Fix.
3. **`layout.tsx`**: page metadata is still the scaffold default ("Create Next App" /
   "Generated by create next app"). Bad for SEO, browser tab, and link previews. → Real title
   + description.
4. **Font wiring**: `globals.css` maps `--font-sans` to `--font-geist-sans`, but `layout.tsx`
   only loads `inter.variable` (and applies the unused `geistSans`/`geistMono` definitions are
   dead). The body uses `font-sans`, which resolves to an undefined var. → Point `--font-sans`
   at the Inter variable that is actually loaded and drop the dead Geist imports.

### Result
- Removed the stray backtick in `floating-card.tsx` (was rendering a literal "`" on the popup).
- Fixed `bg background` → `bg-background` on the discounts card.
- Replaced scaffold metadata with a real branded `<title>` + description.
- Rewired `--font-sans` to the Inter variable that's actually loaded; deleted the dead
  Geist/Fraunces imports from `layout.tsx`. `tsc` clean.

### Insights → next cycle
- **Broken nav links**: `site-header.tsx` links to `find-us` (no page → 404) and `vip`
  (README says delete it). Nav hrefs are also relative (`"menu"` not `"/menu"`), which is
  fragile from nested routes. Cycle 2 = navigation correctness + a real Find Us page.
- **Dead props**: `ImageCard` accepts `titleClassName`/`subtitleClassName` but never uses them;
  the home page passes `font-script`/`font-montserrat` into them, so they silently do nothing.
- **Pre-existing lint**: discounts page has unused `customer`/`setCustomer`; `floating-card`
  sets state in an effect for its fade-in (could be pure CSS). Queue for a cleanup cycle.
